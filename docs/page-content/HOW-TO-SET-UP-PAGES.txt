SETTING UP YOUR PAGES (about 15 minutes)
=========================================

1. UPLOAD THE THEME
   Online Store → Themes → Add theme → Upload zip file → Publish.

2. MAKE 4 NEW PAGES
   Online Store → Pages → Add page.
   For each: type the title, click "<>" in the text box, paste the file, click Save.

   Title                 Paste this file
   --------------------  ------------------------------
   Membership terms      membership-terms.html
   Delivery and access   delivery-and-access.html
   Terms of service      terms-of-service.html
   FAQ                   (leave empty)

   For FAQ only: set Template to "lps-faq".

3. SIMPLER REFUND POLICY (optional)
   Pages → Refund policy → "<>" → replace with refund-policy-simple.html → Save.

4. PICK THE NEW LAYOUTS
   Open each one and set the Template:

   Pages → About                → lps-about
   Pages → Contact              → lps-contact
   Pages → Premium Learning     → lps-premium-learning
   Pages → Perfume development  → lps-perfume-development
   Pages → Software             → lps-software
   Products → Le Parfum Simplifie Access → lps-membership
   Products → Perfumery Software        → lps-software

Done. Or send me an access key and I'll do all of this for you.
