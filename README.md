# Le Parfum Simplifié — Shopify theme additions

Theme files for the Premium Learning customer journey: homepage → `/pages/premium-learning` → `/products/le-parfum-simplifie-membership`. They are built as add-ons to the live **Horizon 4.3.0** theme.

```
assets/     lps.css, lps.js                       shared editorial design system
snippets/   lps-*.liquid                          media/placeholder, intro, icons, editor-only notes
sections/   lps-*.liquid                          12 reusable OS 2.0 sections
blocks/     lps-benefits.liquid                   benefits block for the product purchase panel
templates/  index.json                            homepage
            page.lps-premium-learning.json        Premium Learning page
            product.lps-membership.json           membership product page
```

No Horizon file is modified. See **[docs/REDESIGN.md](docs/REDESIGN.md)** for installation into a duplicate theme, template assignment, the image list, the business details to confirm and the pre-publication test checklist.
